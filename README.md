# Медиатека — консольный CRUD-сервис

Программа для структурированного хранения, фильтрации и многоуровневой сортировки базы данных аудиозаписей. Написана в рамках сессионного задания на 1 курсе.

## Архитектура проекта

Проект спроектирован с разделением логики по модулям (файлам):
* `main.py` — точка входа, инициализирует приложение и запускает главный цикл программы.
* `menu.py` — отвечает за интерактивный текстовый интерфейс и обработку ввода пользователя.
* `sorting.py` — содержит реализацию алгоритма Быстрой сортировки (метод Хоара) для многоуровневых ключей.
* `reports.py` — логика формирования аналитических отчетов согласно техническому заданию.
* `file_operations.py` — модуль для работы с базой данных (чтение и запись текстового файла `database.txt`).

## Как запустить проект
Запустить main.py
